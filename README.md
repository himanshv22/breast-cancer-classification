# breast-cancer-classification
Breast Cancer Classification using Machine Learning

This project applies multiple machine learning classification algorithms to predict whether a tumor is benign or malignant using the Breast Cancer dataset from Scikit-learn.

Models Implemented are
Random Forest Classifier,
Decision Tree Classifier,
AdaBoost Classifier

Features:

Dataset preprocessing

Train-test splitting


Model training and prediction

Accuracy evaluation

Comparative visualization of model performance

Technologies Used:

Python

Scikit-learn

Matplotlib

The implemented models achieved approximately 95–96% classification accuracy on the test dataset.
